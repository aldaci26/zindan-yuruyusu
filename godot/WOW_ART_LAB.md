# WotLK Visual Prototype

This is an isolated art test scene. It does not replace the playable main scene and does not touch save data, combat, quests, inventory, or input bindings.

## Run

1. Open `godot/project.godot` with Godot 4.3.
2. Open `wow_art_lab.tscn`.
3. Press F6 (Run Current Scene).

## First vertical slice

- Existing procedural dwarf warrior model, recolored for a cold Northrend palette.
- Existing wolf model as a creature scale/readability reference.
- New procedural snowfield, ruined gate, rune accents, fir trees, faction banners, fog and directional lighting.
- No Blizzard client files or unverified third-party assets are included.

## Next work

This scene is a lighting, scale and composition baseline. The next step is to import verified, independently licensed rigged character/creature assets and compare them side-by-side before any live-game replacement.
